Privacy

This website

We collect no personal data on this website. It sets no cookies, runs no scripts and loads nothing from other servers.

GitHub hosts it with GitHub Pages, which logs and stores your IP address for security purposes when you visit. What GitHub does with it is up to GitHub and described in the GitHub General Privacy Statement, which also applies when you follow the links to the project on GitHub.

The app

The app sends nothing to us or to anyone else. It connects only to your router, over the USB-C cable, and has no analytics or crash reporting.

Contact

This website and the app are run by the maintainer of Churn. For questions about this statement, write to info@churn.id.
